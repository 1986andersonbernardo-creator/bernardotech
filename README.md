# MONITORE+

Site institucional estático para a MONITORE+, empresa de instalação de câmeras de segurança e venda de equipamentos CFTV.

## Estrutura

- `index.html`, `css/style.css`, `js/main.js` e `img/`: arquivos estáticos servidos pelo Vercel a partir da raiz.
- `public/`: cópia sincronizada da página e dos recursos publicados.
- `img/hero-security.jpg`: imagem otimizada usada no destaque.
- `img/gallery-*-preview.jpg`: imagens otimizadas usadas na galeria de referências visuais.

Não há cadastro de produtos, estoque, autenticação ou banco de dados neste projeto. O site mostra categorias para consulta pelo WhatsApp e não publica modelos ou especificações sem dados confirmados. A galeria apresenta imagens ilustrativas já existentes em `img/`; elas estão identificadas como referências visuais e não como instalações realizadas pela MONITORE+.

## Visualização local

Abra `index.html` no navegador. O projeto não requer instalação de dependências nem etapa de compilação.
